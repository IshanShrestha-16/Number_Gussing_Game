##🎯 Number Guessing Game

A simple and interactive Number Guessing Game built using Python. The computer randomly selects a number between 1 and 100, and the player tries to guess it.

📌 Features

Random number generation using Python's random module.

Hints to help players guess the correct number.

Tells you whether your guess is too high or too low.

Tracks the number of attempts.

Handles invalid inputs using exception handling.

Runs until the player guesses the correct number.

🛠️ Technologies Used

Python 3

random module

try-except exception handling

while loop

Conditional statements (if-elif-else)
